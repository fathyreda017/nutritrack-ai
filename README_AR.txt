NutriTrack AI — تشغيل ونشر من GitHub

الملفات:
- index.html: واجهة التطبيق
- server.mjs: خادم الويب ووسيط طلبات الذكاء الاصطناعي
- package.json: إعدادات تشغيل الخادم

مهم:
1) ارفع هذه الملفات الثلاثة إلى جذر مستودع GitHub (نفس المستوى، لا ترفع ملف ZIP نفسه).
2) عند نشر المستودع على خدمة تدعم Node.js، اضبط أمر التشغيل على: npm start
3) أضف متغير البيئة OPENAI_API_KEY في إعدادات الخدمة فقط. لا تضع المفتاح في أي ملف أو مستودع.
4) اختياريًا اضبط OPENAI_MODEL على نموذج متاح في حساب API لديك. الافتراضي في هذه الحزمة gpt-4.1-mini.
5) فعّل حدود الإنفاق، ولا تنشر الخادم للعامة دون إضافة مصادقة وحماية من إساءة الاستخدام.

الدقة:
القيم التي يقترحها الذكاء الاصطناعي تقديرية وليست قياسًا مخبريًا. اكتب الوزن بالجرام وطريقة الطبخ وكمية الزيت/السمن لتحسين التقدير. اشتراك ChatGPT لا يشمل بالضرورة رصيد API.
